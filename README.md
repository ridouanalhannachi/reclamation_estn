# Réclamations ESTN

Plateforme universitaire de dépôt et de suivi des réclamations étudiantes.

Le dépôt est initialisé pour accueillir une première version sécurisée de l'application. Le développement s'effectue par patches versionnés et branches dédiées, sans suppression des données existantes.

Voir la branche de développement et sa pull request pour les instructions d'installation et la première implémentation.
